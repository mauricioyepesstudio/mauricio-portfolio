# Real Group Entertainment / RGE Portfolio — creative director integration

Use the centralized `mauricioyepesstudio/ai-agency-control-plane` brand registry. Do NOT copy Resource Living's advertising look or EvolUSA's consumer service UI.

**Real Group Entertainment:** art-directed editorial campaign, creative technology and premium storytelling. Sophisticated original concepts, modern high-quality imagery, confident commercially grounded copy. Avoid generic templates and fabricated case studies.

**RGE Portfolio:** authentic case studies and craft, not sales posters; use actual project imagery and visible design/process evidence. Existing website uses near-black, warm white, gold, Inter and Instrument Serif. **Preserve that intentional visual language where appropriate**: premium does not mean all brands must have bright white backgrounds. Improve hierarchy and photography, not replace identity.

Example commands from control-plane checkout:
```bash
agency creative-propose real_group_entertainment real_group_brand_master "Show how creative production elevates a premium business"
agency creative-propose rge_portfolio rge_portfolio_master "Create an editorial case-study cover for an authorized portfolio project" --channel web
```

Each project's artwork must use genuine permitted visuals and approvals. The generated brief is not a rendered asset and does not post, edit live pages or authorize use of external client logos. Use `agency creative-check` on completed metadata and independently inspect final pixels for cropping, legibility, mobile hierarchy and brand consistency.
